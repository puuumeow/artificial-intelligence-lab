# artificial-intelligence-lab# Artificial Intelligence Lab

A collection of practical lab exercises completed as part of the **Artificial Intelligence** course in the BSc in Information & Communication Engineering programme at **Bangladesh University of Professionals (BUP)**.

This repository documents the algorithms, techniques, and concepts explored throughout the course. The notebooks are maintained as academic coursework and learning materials, not as production-ready implementations.

## Contents

| Lab | Topic | Main Concepts |
|---|---|---|
| 01 | Introduction | Introductory AI lab exercises |
| 02 | Uninformed Search | BFS, DFS, and other uninformed search strategies |
| 03 | Informed Search | Greedy Best-First Search and A* |
| 04 | Informed Search | A*, Uniform-Cost Search (UCS), and heuristics |
| 05 | Local Search | Local-search algorithms and optimization |
| 06 | Genetic Algorithm | Genetic algorithm fundamentals and implementation |
| 07 | Constraint Satisfaction | Genetic algorithms, CSP, backtracking, and forward checking |
| 08 | Adversarial Search | Minimax and Alpha-Beta Pruning |
| 09 | Uncertainty | Probabilistic reasoning and Markov chains |
| 10 | Bayesian Learning | Bayesian networks, Naive Bayes, and perceptrons |
